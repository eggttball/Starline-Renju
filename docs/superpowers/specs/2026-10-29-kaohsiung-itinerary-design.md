# 高雄港灣一日行程頁設計

## 目的

在目前連珠遊戲專案新增一個繁體中文、可獨立開啟的單頁行程網站，供 2026 年 11 月 2 日（星期一）高雄部門聚餐團體查看。頁面要讓五位從台北搭高鐵南下的同事和高雄會合後，能按時間、交通路線與地點順序掌握當日安排。

## 頁面結構

- 新增獨立的 `itinerary.html`，不改動連珠遊戲首頁與既有遊戲流程。
- 以港灣散步誌的視覺風格呈現：日期與集合摘要、交通路線示意、上午時間軸、午餐訂位卡、下午固定活動及 optional 遊艇方案。
- 上午路線依使用者提供的時段表：10:00 高鐵左營站下車出站；搭捷運紅線至凹子底；步行轉搭輕軌 C24 愛河之心，至 C13 駁二蓬萊；走訪駁二與哈瑪星鐵道園區、步行至棧貳庫。途中保留看美術館段輕軌景觀的提示。
- 顯示附圖提供的節點：10:00–10:30 出站及轉乘、10:30–11:20 輕軌、11:20–11:50 哈瑪星鐵道園區、11:50–12:05 步行、12:05–12:15 棧貳庫拍照及找餐廳，12:15 抵達後於 12:30 訂位用餐。
- 午餐標示為「徐泰山汕頭火鍋，棧貳庫，12:30 訂位」。午餐結束時間未提供，頁面不可自行填定用餐時長。
- 下午將 15:00 大港橋旋轉秀作為固定時間錨點；棧柒庫 VIVELAND VR 及自駕車排在旋轉秀之後，以現場體驗時長及場次為準，不虛構時段。
- optional 文化遊艇港灣巡航列出每日 13:50、14:50 班次。明確指出 14:50 班次僅距 15:00 旋轉秀 10 分鐘，行程銜接風險高；13:50 班次也需午餐提早結束，且先確認巡航時長及是否能及時回到大港橋。預設主行程不把遊艇列為必排行程。

## 路線與時間表達

- 路線圖用文字與站碼呈現可辨識的順序：高鐵左營／捷運 R16 → 凹子底 R13 → 輕軌 C24 愛河之心 → C13 駁二蓬萊 → 棧貳庫。
- 清楚區分固定開始時間、附圖建議時段、轉乘／步行緩衝、未定時長體驗和 optional 班次。
- 不宣稱即時列車班距、精確乘車分鐘、遊艇航程或 VR／自駕車體驗長度。附圖的時段以使用者提供的參考行程呈現。
- 將「愛河之星」依使用者原始說法與官方站碼名稱可能不一致的地方，以「愛河之心 C24（凹子底轉乘）」標示，避免造成找錯站的疑義。

## 實作範圍

- 靜態原生 HTML、獨立 `itinerary.css` 與少量 `itinerary.mjs`，不新增執行時套件或後端 API。
- `itinerary.mjs` 僅處理必要的行程選項互動，例如標示遊艇是否納入規劃，以及相關時間銜接提醒；在停用 JavaScript 時，所有主要行程和風險提示仍須可讀。
- 桌機以路線總覽和雙欄資訊卡呈現；手機改為單欄垂直時間軸，避免小螢幕橫向捲動。
- 使用語意化標題、清晰對比、鍵盤可操作控制項及減少動態效果偏好。

## 完成條件

- 從既有 Node 伺服器可用 `/itinerary.html` 開啟新頁，原 `/` 連珠首頁保持原樣。
- 所有使用者指定的時間、站點、聚餐地點、活動及 optional 選項均有呈現且順序一致。
- 14:50 遊艇班次與 15:00 大港橋活動的衝突，以及 13:50 班次的條件，都在頁面上明確說明。
- 手機和桌面版都能掃讀完整時間軸、路線和彈性活動。
